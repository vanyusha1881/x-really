X-Really 隐私政策

生效日期：2026 年 9 月 9 日 · 适用于 X-Really · 推文谣言检查器（Chrome 扩展）

概要 无服务器 · 无统计 · 无追踪

X-Really 不运营任何服务器，不收集、不存储、不分析任何用户数据。所有功能均在你的浏览器本地完成；扩展不含广告、不含用户行为统计、不含任何第三方追踪代码。涉及网络的请求均由浏览器直接发往你指定的目标（你配置的 AI 接口与搜索引擎），不经过任何中间服务器。

一、扩展会在本地存储什么

以下数据仅保存在你的浏览器中（chrome.storage），不上传给开发者或任何第三方：

数据存储位置用途清除方式
接口地址、API Key、模型名、功能开关chrome.storage.sync（随你的 Chrome 账号同步）保存你的配置在设置页修改，或卸载扩展
最近 20 条核查历史chrome.storage.local（仅本机）回看核查结果随扩展数据一起清除
模型列表缓存（24 小时）chrome.storage.local避免重复拉取自动过期
核查结果缓存（30 分钟）chrome.storage.local相同推文秒回结果自动过期
模型图片能力检测结果chrome.storage.local记住模型是否支持图片随扩展数据一起清除

二、数据何时、发往哪里

当你主动发起一次核查（点击推文上的「检查谣言」或在弹窗粘贴文本）时，浏览器会直接向以下目标发送请求：

  • 你自行配置的 AI 接口（如 DeepSeek、OpenAI 等）：发送待核查的推文文本，以及推文配图（压缩后）。API Key 仅用于向该接口完成鉴权。
  • 搜索引擎（Google、Bing、DuckDuckGo、百度）：发送由推文内容派生的检索词，用于获取相关报道与辟谣信息。
  • 推文配图 CDN（pbs.twimg.com）：下载推文内的图片用于图文核查。

以上目标均由你配置或由扩展直接指向，开发者无法接触这些请求的内容，也不存在任何中转服务器。各 AI 服务商如何处理你发送的内容，请参阅其各自的隐私政策。

三、权限说明

  • storage —— 在浏览器本地保存你的配置与历史（见第一节）。
  • x.com 网站访问（必需） —— 在推文页面注入「检查谣言」按钮与结果卡片。
  • 接口域名与搜索引擎访问（可选） —— 属可选权限，在设置页点击「保存设置」时按需申请；拒绝后核心的文本核查将无法联网，扩展不会索取除此之外的任何权限，也不会读取你访问过的其他网站内容。

四、免责与致谢

  • AI 判定结果仅供参考，不构成事实认定，请勿作为唯一依据。
  • 核查的推文内容属于公开信息；扩展不会读取你的私信、账号信息或浏览历史。

English Summary

X-Really operates no servers and collects no user data — no analytics, no ads, no trackers. All processing happens locally in your browser.

  • Stored locally only: your settings (API key, base URL, model), recent history, and short-lived caches — via chrome.storage, never uploaded to any server we control.
  • Sent directly from your browser, only when you run a check: the tweet text (and compressed images) to the AI provider you configured; search queries to Google / Bing / DuckDuckGo / Baidu; tweet images to pbs.twimg.com. There is no intermediate server.
  • Permissions: storage for saving settings; required host access is limited to x.com (injecting the check button and result card). Access to your API domain and search engines is an optional permission requested on save; the extension never requests access to other sites you visit.
  • Disclaimer: AI verdicts are for reference only and do not constitute a factual determination.
  • Contact: see the email listed on the Chrome Web Store item page.
