    使用提示

    • 打开 x.com，每条推文操作栏（回复/转发/点赞一排）的末尾会出现「检查谣言」按钮。
    • 也可以点击浏览器工具栏中的扩展图标，直接粘贴文本进行检查。
    • Ollama 等本地服务无需 API Key，接口地址填 http://localhost:11434/v1。
    • AI 判定仅供参考，请勿作为事实认定的唯一依据。
