## v1.0.1

**界面与品牌**

- ⭕ **图标改为圆形**：原圆角方形在扩展管理页与工具栏下观感偏"方"。圆形裁切会切掉四角，故按尺寸分档把主体缩进圆内（128/48 留边、32/16 放大补回主体尺寸），四角透明、无白角。
- 🛠 `tools/build_icons.py` 支持 `SHAPE = "circle" | "rounded"`，可一键从 `icons/source-logo.jpg` 复现整套图标。

**检索策略与性能**

- 🔎 **偏好引擎优先 + 竞速兜底**：Google 可用时自发起时刻起最多等 1.5s（绝对窗口），超时才接受其他引擎结果；明确失败立即回落；不在可用集合（未授权/冷却）时零额外等待。
- ⚖️ **按引擎可信度排序合并**：Google 100 > Bing 70 > DuckDuckGo 60 > 百度 40，同权重再按查询顺序（原文 → 去年份 → 实体组合）。原先按"谁先返回谁在前"，先到的引擎易吃满名额、权威信源反被截断。
- 📈 合并资料上限 **8 → 12 条**，多引擎合并才真正生效。
- ⚡ **检索与配图并行**：两者互不依赖，原为"先等完搜索再下载配图"的串行两段。
- 🧊 **引擎冷却落地 `chrome.storage.local`**：MV3 Service Worker 空闲 30s 即回收，纯内存记录会丢失，导致被墙引擎（实测 Google / html.duckduckgo.com 各 7s 超时）每次核查都被重新探测。
- ⏱ **模型调用 45s 超时**（`AbortController`，覆盖请求+重试+读响应），避免接口卡住时无限转圈。
- 🐞 **修正谣言复核关触发条件**：原先读取尚未赋值的 `result.searched`，使条件恒真——**只要判定为谣言就必然再跑一轮完整模型调用**（本意是"仅当未取到检索资料时复核"），谣言场景耗时翻倍，且复核提示词以"搜索不可用"为前提，对已成功检索的场景是错误前提。
- 📊 核查结果新增分段耗时 `timing`（准备 / 分析 / 复核 / 总计）。

## v1.0.0 (首个正式版)

**权限与合规**

- 🔐 **权限收紧**：必需 `host_permissions` 仅 `https://x.com/*`；API 域名 / 四个搜索引擎 / 推文配图域改为 `optional_host_permissions`，设置页保存时统一申请，后台按权限门控（未授权引擎直接跳过且不计入故障冷却；API 域缺失返回引导性错误）。
- 📄 **隐私政策**：新增 `privacy.html`（中英双语），说明本地存储清单、数据流向与逐项权限用途，供商店隐私权 URL 使用。
- 🏷 **清单补齐**：新增 `author` 与 `homepage_url`。
- 🔒 **本地服务免 Key**：修复 Ollama 等 localhost/127.0.0.1 服务即使不配 API Key 也无法发起核查的问题（此前「测试连接」可用但正式检查会被 `NO_API_KEY` 拦截），popup 状态栏同步感知本地端点。

**界面与品牌**

- ✦ **设置页「情报台」重构**：顶部配置概览仪表盘（服务商 / 模型 / 联网搜索 / 图片理解四格实时状态），接口与多模态配置改为 01–02 步骤式引导，预设卡片玻璃拟态化。
- 🎨 **品牌图标**：以「推文卡片 + 谣言印章 + AI 放大镜」替代原盾牌造型；抠除白底与灰色投影输出透明外角，16/32/48/128 分档处理（小尺寸放大主体以保证工具栏可读性），补齐 32px 高分屏尺寸。

**文档**

- 新增 `docs/ARCHITECTURE.md`（工程架构与关键设计决策）与 `docs/CHANGELOG.md`；README 重排为「口号 / 功能特性 / 使用教程 / 配置 / 工作原理 / 隐私 / 目录结构 / 路线图」结构。
- 内在语意契约不变：全部元素 ID、存储 key、判定三档均未改动，原配置兼容。
