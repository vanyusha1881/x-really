## v1.0.0 (首个正式版)

**权限与合规**

- 🔐 **权限收紧**：必需 `host_permissions` 仅 `https://x.com/*`；API 域名 / 四个搜索引擎 / 推文配图域改为 `optional_host_permissions`，设置页保存时统一申请，后台按权限门控（未授权引擎直接跳过且不计入故障冷却；API 域缺失返回引导性错误）。
- 📄 **隐私政策**：新增 `privacy.html`（中英双语），说明本地存储清单、数据流向与逐项权限用途，供商店隐私权 URL 使用。
- 🏷 **清单补齐**：新增 `author` 与 `homepage_url`。
- 🔒 **本地服务免 Key**：修复 Ollama 等 localhost/127.0.0.1 服务即使不配 API Key 也无法发起核查的问题（此前「测试连接」可用但正式检查会被 `NO_API_KEY` 拦截），popup 状态栏同步感知本地端点。

**界面与品牌**

- ✦ **设置页「情报台」重构**：顶部配置概览仪表盘（服务商 / 模型 / 联网搜索 / 图片理解四格实时状态），接口与多模态配置改为 01–02 步骤式引导，预设卡片玻璃拟态化。
- 🎨 **品牌图标**：以「推文卡片 + 谣言印章 + AI 放大镜」替代原盾牌造型；抠除白底与灰色投影输出透明外角，16/32/48/128 分档处理（小尺寸放大主体以保证工具栏可读性），补齐 32px 高分屏尺寸。

**文档**

- 新增 `docs/ARCHITECTURE.md`（工程架构与关键设计决策）与 `docs/CHANGELOG.md`；README 重排为「口号 / 功能特性 / 使用教程 / 配置 / 工作原理 / 隐私 / 目录结构 / 路线图」结构。
- 内在语意契约不变：全部元素 ID、存储 key、判定三档均未改动，原配置兼容。
